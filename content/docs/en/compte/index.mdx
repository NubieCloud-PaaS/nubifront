---
title: Creating and verifying your account
description: Sign-up, validation by code, and password recovery on Nubiecloud.
---

Your Nubiecloud account is personal: it gives you access to the organizations you are a member of.

## Create an account

On **console.nubiecloud.io**, choose **Create an account** and fill in:

| Field | Rules |
|-------|--------|
| **First name** | min. 2 characters |
| **Last name** | min. 2 characters |
| **Email** | valid address |
| **Password** | min. **8 characters**, including **1 uppercase letter, 1 lowercase letter and 1 digit** |

> 🔒 For security reasons, Nubiecloud returns the same message whether the email already exists or not (so as not to reveal existing accounts).

## Validate the account with the code

After signing up, a **6-digit code** is sent to you by email.

1. Enter this code on the verification screen.
2. Your account is activated, you can create your [organization](/en/docs/organisations).

| Detail | Value |
|--------|--------|
| Format | 6 digits |
| Validity | **24 hours** |
| Resending the code | possible (limited to 5 times per minute) |

> ⚠️ This is a **code to type in**, not a link to click. After 24 h, request a new code via **Resend code**.

## Forgot password

1. On the login screen, click **Forgot password**.
2. Enter your email: a **reset link** is sent to you.
3. From that link, choose a new password (same rules as above).

> ℹ️ The reset link is valid for a short while only; request another one if it has expired.
