Welcome to the **Nubiecloud** documentation — the cloud deployment platform for your web, SaaS and ERP applications.

## Where to start?

- **[Quickstart: from zero to a live app](/en/docs/quickstart)** — the full journey, screen by screen: create your account, your organization and your project, connect a Git repo, build your image, deploy it with its database, then monitor and back up your application.
- **[Key concepts](/en/docs/concepts)** — the Organization → Project → Environment → Application hierarchy, and the difference between building and deploying.

## Deploy

| You want to… | Go to |
|--------------|-------|

| Deploy **one** application | [Deployments](/en/docs/deploiements) |
| Deploy **a whole stack** (several services + databases) at once | [NubiStack](/en/docs/nubistack) |
| Install a ready-to-use application (Odoo, WordPress) | [SaaS / ERP](/en/docs/saas) |
| Add a database or a broker | [Managed services](/en/docs/services-manages) |
