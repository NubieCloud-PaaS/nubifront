Une **région** détermine **où** vos applications s'exécutent. Nubiecloud distingue deux types de régions.

| Type | Description |
|------|-------------|
| **Région Nubiecloud (globale)** | Infrastructure gérée par Nubiecloud, partagée entre toutes les organisations (ex. **Europe**). |
| **Région personnalisée (custom)** | **Votre propre infrastructure** (une VM/serveur que vous connectez), privée à votre organisation. |

> ℹ️ Des régions supplémentaires (Afrique) sont annoncées dans la console comme **« bientôt »** : elles apparaissent dans le sélecteur mais ne sont pas encore activées.

## Choisir une région

La région se choisit à la **création d'un projet** (champ **Région**). Toutes les applications du projet s'exécutent dans la région choisie.

- Les **régions globales** sont disponibles immédiatement.
- Une **région personnalisée** n'est sélectionnable qu'une fois **connectée** (voir ci-dessous).

## Connecter votre propre infrastructure

Vous pouvez raccorder votre propre serveur comme région : Nubiecloud y installe tout le nécessaire et le rattache de façon sécurisée. C'est la fonctionnalité **Connect**.

➡️ Guide complet : **[Connecter mon infrastructure](/docs/regions/connecter-mon-infra)**.
