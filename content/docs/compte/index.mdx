---
title: Créer et vérifier son compte
description: Inscription, validation par code, et récupération de mot de passe sur Nubiecloud.
---

Votre compte Nubiecloud est personnel : il vous donne accès aux organisations dont vous êtes membre.

## Créer un compte

Sur **console.nubiecloud.io**, choisissez **Créer un compte** et renseignez :

| Champ | Règles |
|-------|--------|
| **Prénom** | min. 2 caractères |
| **Nom** | min. 2 caractères |
| **Email** | adresse valide |
| **Mot de passe** | min. **8 caractères**, dont **1 majuscule, 1 minuscule et 1 chiffre** |

> 🔒 Pour des raisons de sécurité, Nubiecloud renvoie le même message que l'email existe déjà ou non (pour ne pas révéler les comptes existants).

## Valider le compte avec le code

Après l'inscription, un **code à 6 chiffres** vous est envoyé par email.

1. Saisissez ce code sur l'écran de vérification.
2. Votre compte est activé, vous pouvez créer votre [organisation](/docs/organisations).

| Détail | Valeur |
|--------|--------|
| Format | 6 chiffres |
| Durée de validité | **24 heures** |
| Renvoi du code | possible (limité à 5 fois par minute) |

> ⚠️ C'est un **code à saisir**, pas un lien à cliquer. Passé 24 h, demandez un nouveau code via **Renvoyer le code**.

## Mot de passe oublié

1. Sur l'écran de connexion, cliquez **Mot de passe oublié**.
2. Saisissez votre email : un **lien de réinitialisation** vous est envoyé.
3. Depuis ce lien, choisissez un nouveau mot de passe (mêmes règles que ci-dessus).

> ℹ️ Le lien de réinitialisation est valable un court instant ; redemandez-en un s'il a expiré.
